# 物见 v1.0.4

本版本集中修复图片重复占用、连续拍摄内存压力、识别队列卡死和本地目录写入风险。

## 主要修复

- 图片压缩改到后台 Isolate，永久文件按内容哈希去重。
- 启动时迁移旧版原图，压缩重复内容并清理旧缓存。
- App 内存储统计新增相机临时图片数量和占用。
- 原生相机限制拍摄分辨率，拍摄或写盘失败后会恢复快门。
- 识别并发限制为 4，请求增加超时、响应体上限和 HTTPS 保护。
- 中断的识别任务在下次启动时自动重新排队。
- 物品与待确认项目合并为原子目录文件，支持备份与损坏恢复。
- 修复 iOS 钥匙串权限缺失导致的启动白屏，并为初始化失败提供重试页。
- Android 备份排除不可跨安装恢复的加密 API Key，避免恢复后安全存储损坏。
- Android release 改用固定生产签名，CI 会校验版本、测试和签名配置。

## 升级说明

同一签名的覆盖升级首次启动后会在后台迁移旧图片。图片较多时可能持续一段时间，但数据会分批保存；迁移完成后旧原图和一小时前的临时图片会自动清理。

正式发布前必须在 GitHub 仓库配置固定 Android keystore Secrets，并完成真机连续拍摄和旧版本升级回归。

早期公开 APK 使用了不稳定的 debug 签名；如果设备上的 v1.0.3 与 v1.0.4 生产证书不同，Android 会拒绝覆盖安装。不要为了安装新版直接卸载旧版，否则本地目录和图片会被删除。必须先确认数据已得到可恢复的保全；旧签名私钥不可用时，签名连续性无法通过代码修复。
