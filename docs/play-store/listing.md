# Google Play 商店资料（简体中文）

## 应用名称

物见

## 简短说明

拍照识别家庭物品，建立可检索的本地物品档案。

## 完整说明

物见把拍照、AI 识别和物品归档连成一条顺手的移动工作流。

你可以用它记录家中、工作室或小型仓库里的物品：拍照或导入图片后，物见会把识别任务放入可恢复队列，调用你选择的视觉模型服务生成结构化信息，再保存为可搜索、可维护的本地物品档案。

主要功能：

• 拍照或导入图片，建立物品记录
• 支持多个预设视觉模型服务和自定义兼容接口
• 识别任务可排队、恢复，网络波动时不轻易丢失
• 按分类、名称和记录内容搜索物品
• 在设备本地保存物品档案和图片
• 导出 PDF、Excel 和 Markdown 文件
• 提供本地存储统计、备份与恢复能力

物见优先采用本地存储。只有在你主动执行识别时，相关图片和请求内容才会发送到你在应用中配置的模型服务。不同服务商的收费、数据保留和处理政策不同，请在使用前查看对应服务商的官方说明。

物见不要求注册独立账号，也不内置广告。使用 AI 识别需要你自行配置可用的模型服务地址、模型和 API Key；相关服务可能产生费用。
